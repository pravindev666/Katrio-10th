# Katrio — Five-Subject Interaction Playbook

| Subject | Primary Effective Media | When 3D Is Justified | Accuracy, Safety & Inclusion Rules |
| :--- | :--- | :--- | :--- |
| **Science (23 Units)** | Controlled 2D physics sliders (ray optics, circuits, waves, thermal), balanced virtual chemistry lab & beakers, biological flowcharts & Punnett workbenches, progressive macro→micro views | Human Heart anatomy/cutaway (Unit 14), carbon/atomic bond geometry (Units 7 & 11), internal plant/organ/brain structures (Units 12, 13, 15, 17) | Accurate SI units & conservation laws; distinguish virtual schematic scale from physical reality; prohibit unsafe synthesis/electrical procedures; full 2D SVG + keyboard fallback for every 3D canvas. |
| **Mathematics (8 Chapters)** | Interactive 2D SVG graphs, function mapping machines, AP/GP staircases, geometric theorem constructions, stepwise KaTeX derivations, coordinate grids, probability repeaters | Mensuration combined solids & net unfolding (Chapter 7 only!) | Show *why* every transformation is valid; verify boundary conditions (e.g., tan 90° undefined); allow keyboard/manual stepping rather than drag-only or MCQ-only maths. |
| **Social Science (27 Units)** | **History:** 2D timelines, historically contextualized SVG maps, bloc comparisons, cause→effect networks. **Geography:** Layered maps with accessible legends & map-pointing mode. **Civics:** Institutional flowcharts & dated policy cases. **Economics:** Illustrative budget/tax/GDP sliders. | Optional NASA/SRTM 3D relief terrain only where elevation directly explains Geography drainage/monsoons (Units 1 & 6) — never decorative 3D for Civics/History! | Never gamify wars, casualties, or colonization suffering; separate facts from historical interpretation; explicitly date updated context notes (e.g., EU 27 members post-2020); label economics rates as illustrative classroom examples. |
| **English (7 Units)** | Illustrated storyboards, character perspective cards, narrative sequence puzzles, line-by-line poem device annotations, contextual vocabulary webs, keyboard grammar editors, optional user-triggered TTS + transcript | None required (preserve optional existing story dioramas only where helpful, never force 3D onto grammar/poetry!) | Respect copyright (no verbatim full poems/prose without rights); accept multiple valid phrasing explanations; never auto-play voice audio; never require microphone recording. |
| **Tamil (7 இயல்கள்)** | Native Unicode Tamil literature annotations, contextual translation bridge, ஐம்பால்/வழு-வழாநிலை/தொகை/யாப்பு grammar studios, line-level simple Tamil explanations | None required (keep lightweight optional cultural visual anchor with full 2D/text parity) | Enforce clean UTF-8 Tamil normalization (`Noto Sans Tamil`), zero corrupted PUA glyphs, authentic Class 10 grammar (never beginner alphabet flashcards), expert Tamil teacher sign-off before marking approved. |
